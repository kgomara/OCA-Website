# OCA Website

Static website for O'Mara Consulting Associates.

## Overview

This repository contains a small static HTML/CSS/JavaScript website. The site is organized around a single `index.html` page with in-page sections for Home, Services, Portfolio, Continuing Education, and Reference Library.

The Reference Library section renders a searchable collection of local PDF references from JavaScript data. The site uses Bootstrap 5.3.8 and jQuery from public CDNs, with project-specific styling and behavior in local files.

## Structure

```text
index.html                  Main single-page website
css/
  oca-styles.css            Project-specific styles
js/
  oca-scripts.js            Section navigation behavior
  oca-bookshelf-scripts.js  Reference Library data
  bookshelf.js              Reference Library rendering and search
img/                        Site images and icons
docs/                       Certificates and document thumbnails
library/                    Reference Library PDF files
api-documentation/          Generated API documentation
```

## Local Preview

The site can be opened directly from `index.html`. For behavior closer to GitHub Pages, run a small local web server from the repository root:

```bash
python3 -m http.server 8010 --bind 127.0.0.1
```

Then open:

```text
http://127.0.0.1:8010/
```

## Publishing

The repository is ready for GitHub Pages publishing from the repository root. In GitHub, use:

```text
Settings -> Pages -> Deploy from a branch -> master -> / (root)
```

## Development Notes

- Open the repository root in VS Code.
- The repository root is the folder containing this README, `index.html`, and the top-level `.git` directory.
- The old Eclipse `WebContent` web root was flattened into the repository root.
- The old Eclipse project metadata and local Bootstrap assets were removed.
- Main site navigation is handled by `js/oca-scripts.js`.
- Reference Library cards are generated by `js/bookshelf.js` from data in `js/oca-bookshelf-scripts.js`.
- API documentation remains available from the site menu.
